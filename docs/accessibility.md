# Доступность мобильного приложения

Задача: [#4](https://github.com/TewCorejz/accessible-ui-constructor-mobile/issues/4) · Проверено: 24.11.2026, iOS-симулятор iPhone 18 Pro (iOS 27)

## Что сделано в коде

| Что | Как |
|---|---|
| Подписи для скринридеров | У всех кнопок-иконок есть `accessibilityLabel` («Поднять виджет «Баланс» выше», «Удалить виджет…», «Закрыть список виджетов») |
| Роли и состояния | Кнопки — `button`, переключатель «Расстановка» — `switch` с `checked`, образцы цветов — `radio` в `radiogroup`, шторка «Шаблоны» и «Показать превью» — `expanded` |
| Заголовки | Заголовки экранов и разделов — `header`, по ним можно перемещаться ротором VoiceOver |
| Озвучка результата | После добавления, перестановки, удаления, сохранения и импорта — `announceForAccessibility` |
| Перестановка без жестов | У позиции виджета («2 из 3») есть действия скринридера «Поднять выше» / «Опустить ниже» — в VoiceOver свайп вверх/вниз, в TalkBack — меню действий |
| Модальная панель | Панель «Добавить виджет» — `accessibilityViewIsModal`: фокус VoiceOver не уходит за неё; жест «Z» закрывает |
| Ошибки | Сообщения об ошибке импорта — `accessibilityLiveRegion="assertive"` |
| Размер целей | Кнопки не меньше 48 × 48 pt, основные — 56 pt |
| Системный размер шрифта | Текст растёт с Dynamic Type / «Размер шрифта» Android, но не больше чем в 2 раза (WCAG 1.4.4); заголовки экранов — до 1,4×, чтобы не обрезаться |

## Проверка с максимальным системным шрифтом (iOS «Accessibility XXXL»)

Найдено и исправлено:

| Было | Стало |
|---|---|
| Заголовок экрана обрезан («Мой бан…» огромным шрифтом) | Заголовок растёт до 1,4×, помещается |
| «Мой экран» и переключатель «Расстановка» вылезали за край | Строка переносится |
| Название интерфейса обрезано («Мой удо…») | Поле многострочное |
| Слова ломались посередине («Перево / д от») в «Истории переводов» | Сумма уходит под название — учитывается реальный размер с системным масштабом |
| Баланс разбивался на две строки | Сумма подгоняется под ширину одной строкой |
| «14 px» уходило за правый край в «Оформлении» | Строка переносится |
| «При / мен / ить» на кнопках | Кнопки встают друг под друга |

## Что получает TalkBack (Android, 24.11.2026)

На эмуляторе Pixel 8 Pro снято дерево доступности Android (`uiautomator`) — именно его читает TalkBack: подписи, роли, состояния, размеры целей. Сам TalkBack на образе эмулятора не установлен, поэтому озвучку на слух это не заменяет.

Работает: все кнопки подписаны; «Режим расстановки» — переключатель с состоянием «включено»; образцы цвета — радиокнопки с «отмечено»; ползунок — «Размер основного текста, 14 пикселей»; у позиции виджета — «Виджет «Баланс», позиция 1 из 3» с действиями перестановки; цели нажатия от 48 dp.

Исправлено:

| Было | Стало |
|---|---|
| Иконки нарисованы шрифтом, и скринридер видел их как текст: вкладка звучала «\uf356, Мой банк», у декоративных иконок — лишние остановки | Все иконки скрыты от скринридера (`src/ui/Icon.tsx`), вкладки — «Мой банк», «Выбрать», «Оформление» |
| Несколько одинаковых «Применить» / «Удалить» во «Выбрать» | «Применить интерфейс «Интерфейс 1»», «Удалить интерфейс «Интерфейс 1»» |
| «Режим расстановки» — 44 dp | 48 dp |

## Что осталось проверить человеку

Симулятор iOS не запускает VoiceOver, поэтому эти пункты — на реальных устройствах:

- [ ] **VoiceOver (iPhone):** пройти «Мой банк» → «Добавить виджет» → выбрать виджет → переставить (свайп вверх/вниз на позиции) → «Сохранить». Каждый элемент озвучивается понятно, порядок фокуса логичный.
- [ ] **TalkBack (Android):** тот же сценарий; действия перестановки — через меню действий.
- [ ] Импорт файла со скринридером: выбор файла, озвучка «Файл проверен…» или ошибки.
- [ ] Ползунок размера текста: VoiceOver называет «14 пикселей» и меняет значение свайпом вверх/вниз.

Как включить: iPhone — «Настройки → Универсальный доступ → VoiceOver» (или трижды нажать боковую кнопку, если настроено); Android — «Настройки → Спец. возможности → TalkBack».
